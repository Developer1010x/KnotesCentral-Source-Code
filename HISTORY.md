# History of KnotesCentral

Four versions, one idea: the notes a batch collects should still be there for
the batch behind it.

## V4 — KnotesNeo (current)

- **Contributors**: S Prajwall Narayana, Krishna Tejaswi
- **What changed**: a full rewrite from hand-written HTML to Next.js, with the
  catalog moved into typed data files that anyone can edit through the GitHub
  web editor.
- **Features**:
  - Department → year → semester → subject browsing, every page prerendered.
  - Search across subject names, codes and note titles, plus a ⌘K palette.
  - Bookmarks, revision progress and a saved semester, stored on the device.
  - An exam-prep view: a whole semester's material in one list.
  - A weekly link checker that tells "deleted" apart from "needs an RVCE
    login", a `/gaps` page listing subjects with nothing working left, and a
    `/rot` report tracking the decay over time.
  - Installable as an app, with offline browsing of pages already visited.
- **Source**: this repository.
